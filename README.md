# Sys_Hes_Anb

یک پروژه دسکتاپی یکپارچه WinForms با VB.NET و Microsoft Access برای مدیریت کاربران، کالا، انبار، خرید و فروش، حسابداری و تنظیمات.

## مشخصات

- Visual Studio 2015
- VB.NET
- Windows Forms
- Microsoft Access 2016 (`.accdb`)
- معماری سه‌لایه: `Data`، `Business`، `Presentation`

## وضعیت این نسخه

این ریپو یک اسکلت اجرایی و قابل توسعه برای MVP است:

- ورود و احراز هویت
- مدیریت کاربران و دسترسی‌ها
- مدیریت کالا و انبار
- ثبت خرید و فروش ساده
- ثبت سند حسابداری ساده
- گزارش‌های پایه
- تنظیمات ظاهری

## راه‌اندازی

1. در Access یک فایل با نام `Sys_Hes_Anb.accdb` بسازید.
2. اسکریپت `Database/CreateSchema.sql` را برای ساخت جدول‌ها اجرا کنید.
3. رشته اتصال در `App.config` را مطابق مسیر دیتابیس تنظیم کنید.
4. پروژه `Sys_Hes_Anb.sln` را در Visual Studio 2015 باز کنید.

## کاربر پیش‌فرض

اگر جدول `Users` خالی باشد، برنامه هنگام اولین اجرا کاربر زیر را ایجاد می‌کند:

- نام کاربری: `admin`
- رمز عبور: `admin123`

> رمزها به‌صورت SHA256 ذخیره می‌شوند.
